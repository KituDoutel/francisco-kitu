## 📖 About

Welcome to my personal portfolio website! I'm Francisco Soares Doutel Sarmento, a passionate programmer, cybersecurity enthusiast, and IoT developer from Dili, Timor Leste 🇹🇱.

This portfolio showcases my skills, projects, designs, and experience in:
- 💻 Web Development
- 🔒 Cyber Security
- 📱 Mobile App Development (Flutter)
- 🌐 Internet of Things (IoT)
- 🎨 Graphic Design

## ✨ Features

- 🎯 **Responsive Design** - Works perfectly on all devices (mobile, tablet, desktop)
- 🌙 **Dark Theme** - Modern dark theme with neon green accents
- ⚡ **Loading Screen** - Smooth animated loading screen
- 🎬 **Scroll Animations** - Elements animate as you scroll
- 📱 **Mobile Menu** - Hamburger menu for mobile devices
- 📧 **Working Contact Form** - Sends emails using EmailJS
- 🎨 **Design Portfolio** - Showcase of graphic design work
- 🔗 **Social Media Integration** - Links to all social platforms
- 🎪 **Interactive Elements** - Hover effects, floating animations, glow effects
- 🚀 **Fast Performance** - Optimized with Tailwind CSS CDN
